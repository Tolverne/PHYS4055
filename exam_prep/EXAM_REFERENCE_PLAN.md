## Initial course-topic index (provisional)

| Topic | Typical question method |
|---|---|
| Angular momentum coupling | Triangle rule, list F/J values, degeneracy 2F+1 or 2J+1 |
| Hyperfine / Zeeman | Choose weak/strong-field basis; E_F = A[F(F+1)-I(I+1)-J(J+1)]/2 |
| 3-j and Wigner–Eckart | Infer zero/non-zero via triangle and m sum, then evaluate angular coefficient |
| E1/M1/E2 | State operator rank and parity, apply J,m and orbital constraints |
| Equivalent electrons / term symbols | Build L,S terms with antisymmetry and Hund rules |
| Radial / nuclear-size corrections | Specify potential and radial normalization; evaluate matrix element or perturbation |
| Radiative lifetimes | Calculate dipole matrix element, Einstein A, sum allowed decay channels |

## Editorial / accuracy gate

1. Identify and cite original PDF page and question number.
2. Write a complete symbolic answer; check all angular-momentum quantum numbers and units.
3. Run mathematical checks (degeneracy sum, triangle inequalities, parity, dimensional analysis).
4. Independently verify coefficients / numerical outputs; do not copy uncertain transcript OCR.
5. Mark question `verified` in the question index only after the original diagrams and signs have been inspected.
