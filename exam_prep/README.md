# Exam-preparation artifacts

Work from *source documents* to *worked notes* to *compact exam navigation*.

- `reference_booklet/`: cohesive explanatory overview, multiple small .tex sections.
- `worked_examples/`: complete, annotated exemplar calculations.
- `formula_sheets/`: fast lookup formula + method + sanity check.
- `past_exam_solutions/`: year-by-year source-verified solutions.
- `assignment_formula_methods/`: extract general methods from the 2026 assignments.
- `practice_questions/`: fresh questions once recurring types are identified.
- `mistakes_and_gaps/`: error log for last-day revision.
- `source_extractions/`: PDF text for search only, not an authoritative representation of maths.

Source filenames and question numbering remain part of every solution's heading. A provisional answer is never presented as an officially verified past-paper solution.

Build master LaTeX files within their folders (or use the GitHub Actions PDF build).
