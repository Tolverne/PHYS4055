                Worked Solution: A Pure-Loss Channel and Conditional Evolution


   1. Joint system–environment state

    The initial joint state is

                                          |Ψin⟩SE = (α|0⟩S + β|1⟩S) |0⟩E.                                      (1)

     Applying the beam-splitter transformations to each term gives
                                √
                              |Ψout⟩SE = α|0⟩S|0⟩E + √η β|1⟩S|0⟩E +  1 −η β|0⟩S|1⟩E                         (2)
                               √
                       = (α|0⟩S + √η β|1⟩S) |0⟩E +  1 −η β|0⟩S|1⟩E.                          (3)

    The first term corresponds to no photon being found in the environment, while the second corresponds to the
     photon being lost into the environment.

   2. Kraus operators

                                                          ˆKj = E⟨j| ˆUη|0⟩E.                                             (4)

                                            ˆK0|0⟩S = E⟨0| ˆUη|0⟩S|0⟩E = |0⟩S,                                       (5)

                                                    ˆK0 = |0⟩⟨0| + √η |1⟩⟨1| .                                         (7)

3. Conditional evolution

  For the environmental outcome j = 0, the unnormalised conditional system state vector is
                                           ˆK0|ψ⟩S = α|0⟩S + √η β|1⟩S.                                     (20)

   Its probability is

                                                p0 = ⟨ψ| ˆK†0 ˆK0|ψ⟩                                          (21)
                             = |α|2 + η|β|2.                                          (22)

  The corresponding normalised conditional state is
                                                   α|0⟩S + √η β|1⟩S
                                           |ψ0⟩S = √                      .                                     (23)
                                                               |α|2 + η|β|2


  This is the no-loss outcome: no photon is found in the environment.

  For the outcome j = 1,
                         √
                                             ˆK1|ψ⟩S =   1 −η β|0⟩S.                                       (24)

  The probability of this outcome is

                                                p1 = ⟨ψ| ˆK†1 ˆK1|ψ⟩                                          (25)
                             = (1 −η)|β|2.                                           (26)

  Provided that p1̸ = 0, the normalised conditional state is, up to an irrelevant global phase,

                                                  |ψ1⟩S = |0⟩S  .                                           (27)


  This outcome corresponds to photon loss: one photon is found in the environment and the system is left in the
  vacuum state.

  which is generally less than one. The trace is the probability that outcome j occurs. The remaining probability

5. Purity of the output state

  Using the normalisation condition,

                                                       |α|2 = 1 −|β|2,                                           (40)

   the output matrix elements may be written as

                                                            ρ′00 = 1 −η|β|2,                                          (41)
                                                            ρ′11 = η|β|2,                                              (42)
                                                               |ρ′01|2 = η|α|2|β|2.                                          (43)

  For a two-dimensional density matrix,
                                       [
                                 Tr  (ˆρ′S)2] = (ρ′00)2 + (ρ′11)2 + 2 |ρ′01|2 .                                (44)


   Substitution gives
                             [         (                         Tr  (ˆρ′S)2] =  1 −η|β|2)2 + η2|β|4 + 2η|α|2|β|2                                 (45)
                                         (                        (                      =  1 −η|β|2)2 + η2|β|4 + 2η 1 −|β|2) |β|2                           (46)
                      = 1 −2η|β|2 + η2|β|4 + η2|β|4 + 2η|β|2 −2η|β|4                      (47)

                      = 1 −2η(1 −η)|β|4 .                                               (48)


  For 0 < η < 1, the factor η(1 −η) is nonzero. Therefore, the output has unit purity only when

                                                             |β| = 0.                                               (49)


  Thus, within this range of η, only the vacuum input

                                                  |ψ⟩S = |0⟩S                                             (50)

  remains pure.

  At η = 1, the channel is the identity and every pure input remains pure. At η = 0, every input is mapped to
   the vacuum state, which is also pure.

  For 0 < η < 1 and |β|̸ = 0, the system becomes correlated with the environment.  Since the total system–
  environment state remains pure under the unitary evolution, the mixedness of the reduced system state is a
  consequence of system–environment entanglement.

6. Photon-number statistics for a one-photon input

  For the input state

                                                 |ψ⟩S = |1⟩S,                                             (51)

  we have α = 0 and β = 1. The output state becomes

                                                                              ˆρ′S = (1 −η)|0⟩⟨0| + η|1⟩⟨1|.                                     (52)

   Therefore,

                             P(n = 0) = 1 −η,    P(n = 1) = η.                                (53)


  Within the single-rail subspace,
