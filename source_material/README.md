# Original source material

Keep original course resources here, separated from the revision notes produced from them.

- `course_information/`: course profile, learning outcomes, official exam instructions, approved formula sheets.
- `lectures/transcripts/`: original transcript TXT files, retaining filenames.
- `lectures/notes_to_identify/`: unsorted original slide PDFs and handwritten notes.
- `lectures/slides_and_handouts/`: original PDFs already matched to lecture topics.
- `lectures/lecture_index.csv`: filename → topic → verified source map.
- `assignments/questions/`: assignment questions.
- `assignments/my_solutions/`: submitted work, separate from model solutions.
- `assignments/feedback_and_solutions/`: feedback or official solutions.
- `past_exams/<year>/`: question papers (never edit originals).

**Copyright and privacy:** This repository is public. Make it private before adding material that is not yours to redistribute, or place those files in a separate non-public source store.

After upload, add a row to `lecture_index.csv` or `exam_prep/source_inventory.csv`. For PDFs, the source of truth is the original rendered document: extracted text can drop symbols or misplace fractions.
