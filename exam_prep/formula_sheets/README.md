# Five-page formula and method draft

`main.tex` imports `01` through `05` in a fixed page order:

1. Angular momentum and term symbols
2. Hyperfine and magnetic field regimes
3. 3-j symbols and Wigner–Eckart
4. E1, M1, E2 selection rules
5. Radial structure, terms and lifetimes

This is a working starter, *not yet* audited against the entire syllabus. The intent is **how to solve** as well as **what formula**. Keep it legible; update individual topic files as questions arise.

Build locally with `pdflatex -halt-on-error main.tex`, or use the GitHub Actions PDF artifacts.
