                  Tutorial Question 1: A Pure-Loss Channel and its Kraus Representation


 A single-rail photonic qubit is prepared in the state

                                   |ψ⟩S = α|0⟩S + β|1⟩S,     |α|2 + |β|2 = 1.                                   (1)

 A pure-loss channel with transmissivity 0 ≤η ≤1 is modelled by coupling the system to an environment initially
in the vacuum state |0⟩E. The joint system–environment evolution is

                                    |0⟩S|0⟩E −→|0⟩S|0⟩E,                                                         (2)
                            p
                                    |1⟩S|0⟩E −→√η |1⟩S|0⟩E +  1 −η |0⟩S|1⟩E.                                  (3)

   1. Find the joint system–environment state after the interaction.


New tool: Kraus representation
  In this problem, the environment is not accessed or measured. The output state of the system is obtained by tracing
over the environment:
                                                h                   i
                                                                         ˆρ′S = TrE  ˆUη (ˆρS ⊗|0⟩E⟨0|) ˆU η†  .                                        (4)

  To evaluate the partial trace, choose an orthonormal basis {|j⟩E} for the environment and insert
                 X
                                                                ˆIE =     |j⟩E⟨j|.                                                (5)
                                                                           j

  The reduced system state can then be written as
              X
                                                                     ˆρ′S =    E⟨j| ˆUη (ˆρS ⊗|0⟩E⟨0|) ˆU η|j⟩E†                                          (6)
                                                             j
              X
                        =     ˆKj ˆρS ˆK†j ,                                                         (7)
                                                             j

where

                                                       ˆKj = E⟨j| ˆUη|0⟩E.                                                (8)

  The operators ˆKj are called Kraus operators. The index j labels an environment basis component used when
performing the partial trace; it does not imply that the environment is measured.
  Each Kraus operator gives an unnormalised contribution

                                                                      eρS,j = ˆKj ˆρS ˆK†j .                                                 (9)

  The trace

                                           wj = Tr (eρS,j)                                              (10)

is the weight of this contribution in the reduced system state.
